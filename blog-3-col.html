Architecture case studies

IQVIA OCE · Enterprise iOS

Improving iOS production reliability

Problem
Customers reported crashes in critical workflows across Orchestrated Customer Engagement. Several squads owned the affected areas, so the team needed a shared way to prioritize fixes.
Technical decisions
I started a reliability initiative with my senior director. I prioritized business-critical flows, used crash analytics and Instruments to trace recurring failures, and coordinated an action plan across squads. I diagnosed a freeze on a configurable screen and changed the component loading logic so the page could render.
Outcome
Teams addressed memory leaks, race conditions, and performance bottlenecks. I used the same investigation to identify similar issues in other components. Production crashes declined after release.

Configurable email tracking

Gap Inc. · Offline architecture

Offline iOS apps for retail store operations

Problem
Store associates depended on mobile tools to manage inventory, stockroom operations, and fulfillment, including in areas with unreliable connectivity.
Technical decisions
I designed offline support across InStock, BackOfHouse, and ShipFromStore so associates could continue working during an interruption.
Outcome
All three apps synchronized changes with the server when connectivity returned.
